# African Icon Library

A free, open-source SVG icon library for African everyday life — starting with Nigeria.

**V2: 30 icons · 7 categories · 24 px grid · regular weight · MIT licensed.**

- **Website** — [icons.neustackstudio.com](https://icons.neustackstudio.com)
- **Downloads** — complete SVG bundle, category packs and metadata from the website
- **Figma Community file** — [African Icon Library — V2](https://www.figma.com/community/file/1688005719745631513)
- **Figma plugin** — [African Icon Library](https://www.figma.com/community/plugin/1687997071772751842) · submitted and currently under Figma review
- **Source SVGs** — `packages/icons/svg/regular`
- **Metadata** — `packages/metadata`

## Use the icons

The easiest route is the website: browse, copy individual SVGs, download the complete ZIP, or use the published Community file in Figma.

To work from source:

```bash
npm install
npm run check
```

Useful development commands:

```bash
npm run dev:web
npm run dev:plugin
npm run release:build
```

`npm run check` runs formatting, linting, icon validation, generated-output verification, type checks, tests and builds.

## Drawing standard

Released icons use a shared 24 × 24 viewBox, `currentColor` paint and a consistent regular-weight drawing system. Validation checks geometry, unsupported elements, embedded text, hard-coded colour, duplicate IDs, metadata/asset agreement and release completeness.

The regular weight is the V2 baseline. Additional weights should be deliberately drawn and reviewed rather than generated by mechanically changing stroke width.
