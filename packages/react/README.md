# @african-icon-library/react

Generated React components for the [African Icon Library](https://github.com/neustackdesign/african-icon-library).

> **Not published to npm yet.** Build it from the repository: `npm install && npm run build`.

## Usage

```tsx
import { TalkingDrum, Danfo, JollofRice } from '@african-icon-library/react';

<TalkingDrum />                                  // 24px, hidden from screen readers
<Danfo size={32} />                              // beside its own visible label
<JollofRice title="Jollof rice" />               // the icon carries the meaning
<Danfo className="text-emerald-600" />           // colour comes from `color`
```

Import icons individually; each lives in its own module so bundlers drop what you do not use.

## Props

Everything an `<svg>` accepts, plus:

| Prop          | Type                                      | Default     | Notes                                                       |
| ------------- | ----------------------------------------- | ----------- | ----------------------------------------------------------- |
| `size`        | `number \| string`                        | `24`        | Sets both axes                                              |
| `strokeWidth` | `number \| string`                        | `1.5`       | Optical adjustment only — not a weight                      |
| `weight`      | `'thin' \| 'regular' \| 'bold' \| 'fill'` | `'regular'` | Falls back to `regular` for undrawn weights                 |
| `title`       | `string`                                  | —           | Sets `role="img"` and `aria-label`. Omit for decorative use |

Only `regular` is drawn today. Passing `weight="bold"` renders `regular` rather than faking a
weight by thickening the stroke.

## Server Components

The components are hook-free, so they render unchanged in a React Server Component. The accessible
name uses `aria-label` rather than a `<title>` element, which would need a generated id.

## Generated

Every component in `src/icons/` is generated by `npm run generate` from the SVG assets. Do not edit
them; edit the asset and regenerate. CI fails if the committed output has drifted.
