# Asset manifest

Every image and video the launch needs, with exact dimensions, its source of truth, and the command
or process that produces it.

**The governing rule: no launch image is drawn by hand from an idea of what the library looks
like.** Every one starts from a real asset produced by a repository script, or from a screen
recording of the real product. That is the same discipline the library applies to its own claims,
and a composited mock-up that overstates the product would undo the whole positioning.

The repository scripts referenced here:

| Command                 | Produces                                                                      |
| ----------------------- | ------------------------------------------------------------------------------- |
| `npm run preview`       | `previews/contact-sheet.html` and `previews/proof-strip-24.svg`                 |
| `npm run release:build` | `release/*.zip`, `release/*.json`, `release/manifest.json` with SHA-256 sums    |
| `npm run generate`      | React components, plugin data, compiled site documents                          |
| `npm run build`         | the website, including `/opengraph-image` and `/twitter-image`                  |

**Palette, everywhere:** paper `#FAF9F6`, ink `#16150F`, accent `#2E7D4F` used once per composition.
Never white — white reads as an unstyled default.

A rights-unclear asset in the launch materials for a library about not shipping things you have no
rights to is the worst available own goal. If provenance is unclear, do not use it.

## Build order

1. `npm run check` — everything downstream is invalid if this fails.
2. `npm run preview` → 1.1, 1.2.
3. Export 1.3, build 1.4 from the real `talking-drum` asset.
4. `npm run build`, screenshot 1.5 and 1.6.
5. Deploy, then capture section 2 in both themes.
6. Build the plugin, run it in Figma desktop, capture section 3.
7. Composite section 4 from sections 1–3. **No new drawing at this stage.**
8. Build section 5 from sections 1–4.
9. Record section 6 last, against the finished product.

## Checks before anything ships

- [ ] Every count in an image was substituted from repository state that day.
- [ ] No image shows a weight picker with `thin`, `bold` or `fill` selected.
- [ ] No image shows a drawing that is not in the released set.
- [ ] No image shows a coloured `nigeria-flag` or `football-jersey`.
- [ ] No image contains letters or numerals inside an icon frame.
- [ ] Every screenshot is from the real product at the current version.
- [ ] Every third-party asset is recorded in `credits.md` with its licence and permission date.
- [ ] Dark-theme screenshots exist for every light-theme one in section 2.
