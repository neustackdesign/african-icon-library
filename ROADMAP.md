# Roadmap

African Icon Library V2 starts with a deliberately focused Nigeria-first release. The roadmap is to grow coverage without weakening the visual system or turning the repository into a collection of unrelated drawings.

## Now

- Publish the V2 website, direct SVG downloads and GitHub source.
- Publish the V2 Figma Community file.
- Submit the companion Figma plugin.
- Continue refining and expanding the Nigeria set using the same 24 px drawing standard.
- Improve naming and cultural review with contributors who know the referents being represented.

## Next

- Add high-value missing concepts where the cultural reference and product use case are clear.
- Strengthen category coverage before adding more visual variants.
- Improve contribution tooling, aliases and deprecation support as the library grows.
- Test a deliberately drawn bold weight once the regular set is stable enough to justify maintaining multiple complete weights.

## Later

- Expand beyond Nigeria with regional contributors and reviewers rather than treating “Africa” as one interchangeable visual vocabulary.
- Consider additional weights only when they can be drawn and maintained across the complete released set.
- Explore an illustration tier separately from the icon system if there is enough demand to justify a second visual product.

## What will not change

- The repository remains the canonical source for released SVGs and metadata.
- Figma, the website and downloadable assets must all match that canonical release set.
- New weights will be drawn, not produced by mechanically changing stroke width.
- Cultural names and references should be grounded rather than guessed.
- Generic UI icons are not the focus; the library exists to cover African-specific concepts that mainstream libraries routinely miss.

The current released set is listed in [docs/v2-release-manifest.md](docs/v2-release-manifest.md).
